## 偏りについて

現状の投入は、観察者が「光」より構造的な摩擦・弱い側面を多く見ている標本が多い。  
平均像ではないが、**同じ構造を体験している他者理解**には有用、という方針で昇格している。  
ファイル先頭コメントに偏り注記がある場合はそれを優先する。

## ルール

- `_drafts` の固有名詞・物語は入れない
- 昇格は翼ごとに別指示で行う
- C欄（相互理解シード）は本ディレクトリに入れない → relationship ④⑤
- 下書きは `_TEMPLATE.md` の **共通識別メモ**（姉妹翼／競合／健全時／本能）を推奨
- 姉妹対比の例: `_drafts/wings/_PAIR_2w1_2w3.md`
