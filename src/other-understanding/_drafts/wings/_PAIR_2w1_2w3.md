# 姉妹翼対比 — 2w1 × 2w3

> `_drafts/wings/type2w1.md` / `type2w3.md` から参照。正本昇格時は一般化して各 profiles に反映。
> 2026-08: 両翼とも**日常〜健全主軸**に入れ替え済み（応力は対照）。

## 対比表

| 軸 | 2w1 | 2w3 |
|----|-----|-----|
| 愛の質 | 義務・正しさのある守り | 魅力・成果・役立ちで愛を実感 |
| 翼の色 | 1＝使命・倫理・「やらねば」 | 3＝成功・適応・伝わる役立ち |
| 健全時 | 温かく助け、境界も残せ始める | 明るく貢献し、成果と関係を両立・委任可 |
| 平均時 | 世話焼き＋軽い義務感 | 役立ち条件・「一緒」増・修復努力 |
| 応力時（対照） | 失う恐れ→力への接近→妨害者敵視→愛の名の倫理逸脱 | 自己犠牲の価値証明・共依存・ドラマ優先・別ルート成功固執 |
| 恥の扱い | 「正しく助けられなかった」自責 | 「役に立てない／魅力がない」空虚 |
| 見返り | 必要とされること＋道徳的正しさ | 必要とされること＋認められる成功 |
| 競合誤診 | 1w2（正しさ優先に見える）／6（忠誠） | 3w2（魅力が主に見える）／9w8（英雄に見える） |

## 共通の2核

- 愛されたい・必要とされたい・助けたい
- 援助が自己価値の証明になりやすい
- 境界より相手のニーズが先に来やすい（平均）／健全時は必要確認できる

## 切り分けの一文

- **2w1:** 「正しく守るために、丁寧に助けたい（やらねばは手放し始められる）」  
- **2w3:** 「役に立ち、伝わる成果でも、愛と価値を同時に満たしたい（そばにいなくても価値を信じ始められる）」
